# Console Command Center v0.3.9 Beta

This version applies the compact command-card layout introduced for Untested commands to the established command catalog.

## Compact command catalog

- Established categories, Favorites, and Recent now display commands in a two-column grid.
- Search and Untested retain their collapsible group headings while using the same compact card presentation inside each group.
- Paired cards share row height for a clean, consistent layout.
- Windows narrower than 1,180 pixels automatically return to a single-column layout so inputs and action buttons remain usable.
- Command behavior, categories, fields, warnings, favorites, and confirmation steps are unchanged.

v0.3.9 retains the complete v0.3.8 command library: 141 established entries plus 1,550 isolated Untested entries.
