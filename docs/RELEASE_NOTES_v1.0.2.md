# Console Command Center v1.0.2

Version 1.0.2 fixes command-specific browser filters persisting after a selection.

## Fixed

- Returning a Perk, Power, Effect, item, or other filtered selection to a command now clears the temporary ID Browser filter.
- Opening the standalone ID Browser always starts with every category available.
- Updated requirements and launch instructions for OSF UI 2.0 and OSF Settings 1.0.0. CCC's legacy bridge remains supported by OSF UI's compatibility layer.

The first-run guide and other usability improvements introduced in v1.0.1 are included.
