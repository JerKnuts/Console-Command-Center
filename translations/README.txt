INSTALL A TRANSLATION

1. Copy the translation JSON file into this folder:
   Starfield/Data/SFSE/Plugins/OSF/UI/views/console.command-center/main/translations/
2. Start CCC. The translation is selected automatically unless you previously chose a language.
3. To switch languages, open CCC Settings and choose one.
4. After editing the JSON, click Reload Translation again.

Use UTF-8 JSON. Missing translations use English.
Chinese-example.json is only a partial example and is never selected automatically.

Browser preview: use the source project's translations/ folder instead.
To create a translation, follow README.md in the translator kit.
