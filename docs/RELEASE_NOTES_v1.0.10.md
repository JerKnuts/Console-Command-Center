# Console Command Center v1.0.10

Version 1.0.10 refines the paired speech override controls introduced in v1.0.9.

## Changes

- Speech Challenge Success now uses a normal half-width Gameplay card.
- Speech Challenge Failure now uses a normal half-width WIP card.
- Each card stacks its Always and Restore Normal actions vertically for a more compact layout.

## Validation

- Automated query and command-card tests pass.
- OSF UI validation and production build pass.
- The native plugin builds with the v1.0.10 version string.
