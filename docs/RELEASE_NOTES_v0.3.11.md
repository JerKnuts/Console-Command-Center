# Console Command Center v0.3.11 Beta

This version separates established-command search from the isolated Untested command library.

## Separate search scopes

- The main search now returns only established commands.
- Main-search input no longer loads or searches the 1,550-entry Untested library.
- The Untested screen has its own clearly labeled search field and clear button.
- Untested search covers prepared test cards, engine console commands, and script functions.
- Matching Untested groups open automatically and show a matching-result count.
- Clearing Untested search restores the normal collapsible-group view.

Command execution, verification status, and catalog contents are unchanged.
