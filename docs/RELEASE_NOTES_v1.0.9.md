# Console Command Center v1.0.9

Version 1.0.9 introduces reusable dual-action command cards for related enable and restore commands.

## Combined speech controls

- **Speech Challenge Success** combines Always Succeed and Restore Normal on one full-width Gameplay card.
- **Speech Challenge Failure** combines Always Fail and Restore Normal on one full-width WIP card.
- The forced-result action uses the primary blue control. Restore Normal remains a separate secondary control.
- Each action displays and executes its own console command, uses its own confirmation level, and creates an accurate Activity Log entry.
- Searching, favorites, Recent Commands, and category counts treat each pair as one card.

The catalog now contains 147 established command cards and 1,539 WIP cards.
