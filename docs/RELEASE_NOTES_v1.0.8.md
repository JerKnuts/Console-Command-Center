# Console Command Center v1.0.8

Version 1.0.8 incorporates the October 3 WIP test results and cleans up the established search results.

## Verified commands promoted from WIP

- **Show First-Person Model in Third Person** moved to Camera.
- **Toggle All Actor Animations** moved to World.
- **Select Next Actor** and **Select Next Reference** moved to Targets.

## WIP result updates

- Save Game by Name is unavailable under Executed — Issues after repeated rejection while Starfield's normal save controls worked.
- Load Game by Name is unavailable under Executed — Issues after an existing displayed save name did not load.
- PrintMessage and ToggleMovement moved to Executed — Effect Unconfirmed after producing no visible result.
- Toggle Full Screen Motion Blur, Toggle Bound Visualization Geometry, and Toggle Detection Stats are recorded as effect unconfirmed.

## Cleanup

- Removed the second Toggle Game Pause card from established search results. The verified `tgp` Gameplay command remains.
- Updated the catalog to 148 established commands and 1,540 WIP entries.
