# Console Command Center v0.3.12 Beta

This version moves the separate Untested search into the normal top-right search position.

## Context-sensitive search position

- Normal command screens use the top-right field to search established commands only.
- Opening Untested keeps the field in the same position but changes it to Untested-only search.
- The placeholder clearly identifies the active search scope.
- Search text is kept separately for the established and Untested catalogs.
- The existing clear button clears whichever search scope is currently active.
- Untested commands remain excluded from normal search results and continue loading only when Untested is opened.

Command execution, verification status, and catalog contents are unchanged.
