# Console Command Center v1.0.11

Version 1.0.11 adds page-specific guidance throughout CCC.

## Changes

- Help now opens a dedicated guide for Recent Commands, Favorites, command categories, ID Browser, Quest Browser, Custom Command, or Activity Log according to the page currently displayed.
- Each guide explains the actions and safety details that matter on that page.
- The first-time welcome remains a separate overview and can be opened from every contextual Help window.
- Contextual Help closes with Close, Done, backdrop click, or Escape without closing CCC.

## Validation

- Automated query and interface-source tests pass.
- OSF UI compatibility validation and production build pass.
- The native plugin builds with the v1.0.11 version string.
